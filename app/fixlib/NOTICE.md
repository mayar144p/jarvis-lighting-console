# Bundled fixture libraries

Jarvis ships two community fixture libraries so lights can be found and
added offline. Neither was written by the Jarvis project, and both are
redistributed unmodified inside the zips, under their own licences.

| File | Library | Licence | Source |
|---|---|---|---|
| `ofl.zip` | Open Fixture Library | MIT (`LICENSE-OFL.txt`) | https://github.com/OpenLightingProject/open-fixture-library |
| `qlcplus.zip` | QLC+ fixture definitions | Apache License 2.0 (`LICENSE-QLCPLUS.txt`) | https://github.com/mcallegari/qlcplus |

Each zip holds the original fixture files under `fixtures/`, plus
`index.json` (a search index generated by Jarvis) and `meta.json`, which
records the exact commit the files were taken from.

The files were only repackaged: nothing in them was changed. Jarvis reads
them at install time with `app/fixlib.py`.

To refresh from upstream, run:

```
python tools/build_fixture_libraries.py
```

Thanks to everyone who contributes fixture definitions to both projects.
